# Java Course Exercises

Exercises and practical work for the second-year OOP course at the University of Sidi Bel Abbes.

## Find an Exercise

Course materials are grouped into folders such as `TP0/` and `TP1/`. More TPs and TDs will be added as the course progresses, so check the repository for new folders and files.

Open the matching `.java` file to read an exercise. Each exercise is a separate program.

## Run an Exercise

Install a JDK, then compile and run a file from the repository root. For example:

```bash
cd TP1
javac Task1.java
java Task1 12 15 18
```

Use the arguments requested by the exercise. You can also clone or download this repository to get the latest exercises.
